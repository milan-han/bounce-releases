# Bounce

Share and listen to each other's songs.

## Windows

Download **Bounce-Setup-1.0.0.exe** from the [latest release](../../releases/latest) and run it.

Windows SmartScreen will say it "protected your PC" because the installer isn't code-signed yet. Click **More info → Run anyway**.

When Bounce opens, paste the invite code you were sent.
